## Common Topics

### Screen Time access

PhoneAware uses Apple’s Screen Time technology to show usage insights and support app limits.

If data is not appearing:

- Open iPhone Settings
- Make sure Screen Time access is enabled for PhoneAware
- Reopen PhoneAware

If access was recently changed, iOS may take a short time to refresh the available data.

### Usage data not updating

PhoneAware relies on Screen Time information provided by iOS.

Because this data is controlled by the system, updates may occasionally be delayed.

Try:

- Reopening PhoneAware
- Pulling to refresh where available
- Restarting your iPhone if the issue continues

Historical data is based on what iOS makes available and may not always be complete.

### Daily app limits

PhoneAware can apply daily limits to selected apps.

When a limit is reached, the selected app is blocked until you choose to keep the block or unblock it until midnight.

If a limit is not working:

- Confirm Screen Time access is enabled
- Make sure the app is still included in your selected limits
- Reopen PhoneAware
- Restart your iPhone if necessary

### Mindful Pause

Mindful Pause creates a short moment before continuing into selected apps.

Scheduled Mindful Pauses require a personal Apple Shortcuts automation.

If a scheduled pause is not appearing:

- Confirm the Mindful Pause schedule is enabled in PhoneAware
- Check that the corresponding Shortcuts automation is still active
- Make sure the automation is configured to run automatically
- Reopen PhoneAware after changing the schedule

### Widgets not updating

Widget refresh timing is controlled by iOS.

PhoneAware requests fresh information when possible, but widgets may not always update immediately.

If a widget appears outdated:

- Open PhoneAware to refresh the latest information
- Wait briefly for iOS to refresh the widget
- Remove and add the widget again if the issue continues

### Live Activity and Dynamic Island

Make sure Live Activities are enabled for PhoneAware in iPhone Settings.

Dynamic Island features require a supported iPhone model.

Live Activity information depends on updates allowed by iOS and may occasionally be delayed.

### Premium purchase

PhoneAware Premium is a one-time lifetime purchase. There is no subscription.

If you already purchased Premium and it is not showing as unlocked:

1. Open PhoneAware
2. Open the Premium screen
3. Tap **Restore Purchases**

Make sure you are signed in with the same Apple Account used for the original purchase.

### Restore Purchases

Restore Purchases does not charge you again.

It asks the App Store to check whether your Apple Account already owns PhoneAware Premium.

### Changing appearance

You can change PhoneAware’s appearance from Settings.

Choose:

- System
- Light
- Dark

System follows your iPhone’s current appearance setting.

## Privacy

PhoneAware is designed to keep your usage information private.

Screen Time data is accessed using Apple’s Screen Time frameworks and is used to provide features inside PhoneAware.

For more information, please see the PhoneAware Privacy Policy.
