## Common Topics

### Screen Time access

PhoneAware uses Apple's Screen Time technology to show your device activity.

If usage data is not appearing, make sure Screen Time access is enabled for PhoneAware and reopen the app.

### Usage data not updating

Screen Time information is provided by iOS and may occasionally take some time to refresh.

Try reopening PhoneAware or restarting your iPhone if the issue continues.

### Widgets not updating

Widgets are refreshed by iOS. Open PhoneAware to refresh the latest information.

If necessary, remove and add the widget again.

### Live Activity and Dynamic Island

Make sure Live Activities are enabled for PhoneAware in iPhone Settings.

Dynamic Island features require a supported iPhone model.

### Premium purchase restore

If you already purchased PhoneAware Premium, open the Premium screen and choose Restore Purchases.

### App feedback

If something is not working as expected, please include your iPhone model, iOS version, and a short description of the issue.
